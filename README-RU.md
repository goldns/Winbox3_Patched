# WinBox 3.43.0.1 для MikroTik RouterOS 7.25+

**Нашли баг или нужна доработка? Пишите мне в Telegram: [@kamgoldns](https://t.me/kamgoldns).**

[English](README.md) | Русский

Классический WinBox 3 для Windows x64 с патчами совместимости с MikroTik RouterOS 7.25+. Привычный интерфейс, исправления CMR, возвращённые кнопки и поддержка новых типов полей.

Запустите **[winbox64.v3.43_patched.exe](winbox64.v3.43_patched.exe)** и подключайтесь как обычно. Установка и Python для запуска не нужны.

## Что входит

| Патч | Изменения |
| --- | --- |
| `patch_mark99i_1` | Подключение к новым RouterOS и обработка неподдерживаемых элементов интерфейса |
| `patch_mark99i_2` | Встроенные иконки и их извлечение при запуске |
| `patch_mark99i_3` | Выравнивание стека при запуске, защита Format Drive и иконка Switch |
| `patch_mark99i_4` | Редактирование полей `bytes` и `bigbytes` |
| `patch_mark99i_5` | Модели CMR, защиты Dashboard и иконки |
| `patch_mark99i_6` | WiFi realms, Container ENV, масштабирование, большие счётчики и другие исправления интерфейса |
| `patch_mark99i_7` | Адаптированный **Settings → Swap title order** с сохранением выбора |
| `patch_1-core` | Настраиваемая версия приложения и защита `bigbytes` от переполнения |
| `patch_2-cmr` | Возвращённые кнопки Packages и Container; исправление падения CMR Dashboard |
| `patch_3-bigfixedpoint` | Отображение 64-битных чисел с фиксированной точкой, включая статистику NTP |
| `patch_4-biginterval` | Отображение 64-битных длительностей, включая BSS On Time в Flat Snoop |
| `patch_5-bignumberrange` | Просмотр и редактирование Range в **Routing → Filters → Num Set** |
| `patch_6-u32vector` | Передача ID устройств в диалоги CMR Pair/Upgrade |
| `patch_7-tags` | Редакторы Labels, Port Labels и Order с отдельным выбором режима и имени |
| `patch_8-bargraph` | Столбчатые графики Access Points / Stations, страницы и прокрутка Dashboard |
| `patch_9-topolayout` | Топология CMR: узлы, связи, сохранение позиций, масштаб, перемещение и вложенные карты с Back |
| `patch_10-powercycle` | Выбор интерфейсов в Power Cycle и отдельная команда для каждого выбранного порта |
| `patch_11-ping-fields` | Отдельные селекторы Interface и VRF в Ping и Traceroute |
| `patch_diagnostics` | Отдельная сборка с дампом ресурсов и пропущенных полей |

Range принимает число (`55`) или беззнаковый 64-битный диапазон (`5-55`). В Labels и Port Labels доступны обычный режим, `+` и `−`; в Order — обычный и `−`. Pair/Upgrade открывает отдельный диалог для каждого устройства.

В **CMR Topology** перетащите узел и отпустите мышь, чтобы сохранить его положение. Дождитесь `Saved` — позиция останется после повторного открытия карты. Пустое место можно тянуть для перемещения карты, колесо меняет масштаб, **Fit** вписывает схему в окно. **Esc** отменяет перенос до отпускания мыши. Координаты сохраняются сразу: Apply не нужен, а Cancel не отменяет уже сохранённую позицию.

Двойной щелчок по узлу с **Target Layout** открывает связанную карту. **Back** возвращает предыдущую схему с прежним масштабом и положением. `View: …` показывает имя просматриваемой карты; внешние поля и кнопки редактора относятся к исходной схеме.

В **Tools → Ping** и **Tools → Traceroute** доступны отдельные селекторы **Interface** и **VRF**. Оставьте их незаданными для обычного запуска или выберите интерфейс и VRF для проверки.

**Settings → Swap title order** меняет порядок имени устройства и данных подключения в заголовке окна. Выбор хранится в `winboxpatch-title.dat` в папке профиля WinBox.

## Собрать самостоятельно

Понадобятся **Python 3.10+**, [patch_winbox.py](patch_winbox.py) и [оригинальный WinBox 3.43 x64](winbox64.v3.43_orig.exe) в одной папке:

```powershell
python .\patch_winbox.py
```

Получится `winbox64.v3.43_patched.exe`. Все вставки и иконки уже находятся в скрипте — библиотеки и компилятор устанавливать не нужно. Существующий патченый EXE заменяется автоматически. Оригинал сохраняется.

Патчер проверяет SHA-256 официального оригинала, байты в местах патчей и размеры файлов. Контрольные суммы промежуточных и готовых сборок не ограничены. Чтобы сохранить отдельную копию, используйте `--output another.exe`.

Версия приложения задаётся в начале скрипта:

```python
WINBOX_VERSION = "3.43.0.1"
```

Формат — `A.B.C.D`, каждое число от 0 до 65535, всего не более 11 символов. При пересборке обновятся заголовки окон и версия в свойствах файла Windows. Версия патчера — **1.0.0**.

## Диагностика

Для разбора багов можно собрать отдельный диагностический EXE:

```powershell
python .\patch_winbox.py --dump-skipped-fields
.\winbox64.v3.43_diagnostic.exe
```

Подключитесь и откройте нужное окно. Загруженные ресурсы и журнал `skipped-fields-<PID>.tsv` появятся в **`winbox-dump` рядом с EXE**. В TSV попадают описания пропущенных полей, а не введённые значения. Обычная сборка дампы не пишет.
